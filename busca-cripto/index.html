UTILITÁRIO LOCAL · WINDOWS 10

🔎 Busca de carteiras e vestígios de criptomoedas

Investigue arquivos antigos de Bitcoin, MultiBit, Electrum, Litecoin e outros softwares, sem abrir carteiras nem enviar seus dados.

1. Baixe o script

Salve Busca-Cripto.ps1 na pasta Downloads.

⬇ Baixar Busca-Cripto.ps1

Se o navegador mostrar texto, pressione Ctrl+S e salve como Busca-Cripto.ps1 (não .txt).

2. Abra o Windows PowerShell

No menu Iniciar, procure por Windows PowerShell e abra como administrador. Execute um dos comandos:

Busca inicial

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\Busca-Cripto.ps1"

Busca completa, incluindo nomes dentro de ZIPs

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\Busca-Cripto.ps1" -Completo -VerZips

3. Veja os resultados

O script cria uma pasta BuscaCripto-... na Área de Trabalho com resumo.txt e resultados.csv. Prioridade ALTA sinaliza possíveis arquivos de carteira, não saldo confirmado.

Cuidados importantes

  • O script não altera arquivos de carteira, não busca senhas, não transmite dados pela internet.
  • Não compartilhe wallet.dat, seeds, senhas ou chaves privadas.
  • Em HDs antigos, evite instalar programas e gravar novos arquivos antes de preservar dados, especialmente se houve formatação.
  • Buscas por nome não garantem que a carteira exista ou tenha saldo; podem não localizar arquivos apagados.
